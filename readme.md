# 4ButtonCalc

4ButtonCalc is a simple calculator app for Garmin Connect IQ devices without a touchscreen. If your device has a touchscreen this app wont work, use the Garmin calculator app instead. It is intended for simple calculations in the feld. For anything more complex or mission critical use a real calculator.

## Features

- Basic arithmetic operations
- Supprot for negitive numbers
- Support for decimals
- Unit converter

## Controls

- UP    Increment digit
- DOWN  Decrement digit
- ENTER Next digit
- BACK  Previous digit / Exit
- HOME  Exit

## Requirements

- Garmin Connect IQ SDK
- A compatible Garmin device or the Connect IQ simulator
